Chipload 0.23.0 user guide

Project file

A project (.chipload) is a JSON file. Chipload writes every field; when you write one by hand or with a script, the fields marked no may be left out. Lengths are in mm, angles in radians, feeds in mm/min. chipload schema project prints the JSON Schema this page is made from.

Schema version 29. Older files load through Chipload’s migrations; this schema describes only the current version.

The file

FieldTypeRequiredMeaning
active_partinteger or nullnoThe part new operations go into (its id). Null or no such part: the first part. Only the app and the command line read it; it changes nothing that is cut.
drawingDrawingyesThe drawing: the shapes Chipload cuts, imported from a DXF or drawn in Chipload.
machineMachineyesThe machine: post-processor, safe height, limits and zero.
operationslist of OperationyesThe operations, cut in this order: grouped by part, in the parts’ order.
partslist of PartyesThe parts: groups of operations, each cut with its copies before the next part. At least one.
schema_version29yesThe version of the file format. Chipload upgrades older files when it reads them, and refuses newer ones.
stockStockyesThe material on the machine.
toolslist of ToolyesThe tools the operations cut with.
written_bystring or nullnoThe Chipload version that wrote the file, for reference.

AutoThreshold

The word “auto”.

One of: "auto".

Copies

A grid of copies of a part: copy (column c, row r) is the part moved by (c·dx, r·dy) mm.

FieldTypeRequiredMeaning
columnsintegeryesCopies along X, at least 1.
dxnumberyesDistance from copy to copy along X, mm; negative grows to the left.
dynumberyesDistance from copy to copy along Y, mm; negative grows downwards.
orderCopyOrdernoby_operation: each operation on every copy, then the next; by_copy: every operation on one copy, then the next copy.
rowsintegeryesCopies along Y, at least 1.

CopyOrder

In which order the copies are cut.

  • "by_operation": Each operation on every copy, then the next operation.

  • "by_copy": Every operation on one copy, then the next copy. Called by_part before parts came (schema 22).

Entry

How the tool goes down into the material at the start of each pass, for pockets and follow paths (a profile always spirals: its ramp_angle).

"type": "plunge"

Straight down: needs a centre-cutting tool. An empty struct variant, as Rings.

"type": "ramp"

Down along the path and back, never steeper than ramp_angle (radians, 0 < angle <= 30°).

FieldTypeRequiredMeaning
ramp_anglenumberyesThe steepest the ramp goes, radians: more than 0, at most 30° (0.5236).

"type": "helix"

Pockets only: down round a circle of radius (the tool centre’s), never steeper than ramp_angle.

FieldTypeRequiredMeaning
radiusnumberyesThe helix’s radius, mm: less than the tool radius.
ramp_anglenumberyesThe steepest the helix goes, radians: more than 0, at most 30° (0.5236).

ImageThreshold

Where grey turns black: “auto” or a grey value.

  • AutoThreshold: Picked from the picture.

  • integer: Grey values below this are black, 1 to 254.

ImageTrace

What a picture is traced into.

  • "outline": Closed outlines round the black parts, black inside.

  • "centre_line": Open (or closed) paths along the black strokes’ middles.
