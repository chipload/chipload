**2.5D CAM for CNC routers and mills: drawings in, checked G-code out.** Free software for
Linux, Windows and macOS, written in Rust.

- Profiles, pockets, V-carving, follow paths and holes, from DXF drawings, text and pictures.
- Every program goes through an independent checker before it can be written.
- A material-removal simulation, cycle times and a setup sheet before you cut.
- GRBL, LinuxCNC and Mach3/4 posts, in mm or inches; scriptable, and drivable by AI assistants.
